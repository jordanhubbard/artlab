# Artlab v1.5.0

Long Winter: Second Mix expands the demoscene performance into nine acts inspired
by Scandinavian winters and the Amiga demoscene, with a distinct song for each act.

**Live app:** https://jordanhubbard.github.io/artlab/#long-winter

## Long Winter: Second Mix

- A 2:02 performance moves through Blue Hour, Fire in the Snow, Fjord Mirror,
  Aurora Code, Birch Run, Loose Pixel, Copper Tunnel, Whiteout / Color Storm,
  and First Light.
- Each act has its own melody, chord progression, bass line, and drum pattern,
  with bell, pluck, and chip lead sounds across the score.
- Moonlit fjords, snowy mountains, a red cabin, pine and birch forests, frozen
  water, and animated auroras establish the Nordic winter setting.
- Copper bars, vector balls, checkerboard floors, colorful tunnels, and a
  greetings scroller bring Amiga-inspired motion and color to the stage.
- Whiteout becomes a saturated color storm with restrained bloom and a wireframe
  core, preserving contrast and visible silhouettes.
- Pip gains running and conducting animations. Arrow keys move between acts;
  the overlay identifies the current act, song, and lead sound.
- Instanced forests and checkerboards reduce draw calls, alongside adaptive
  density for slower devices.

## Validation and distribution

The implementation passed lint, the production build, 536 unit tests, and the
Long Winter browser test. Manual Chromium checks exercised audio start and act
navigation and inspected the winter scenery, aurora, tunnel, and color storm.

`artlab-v1.5.0-dist.zip` contains the production site built for the `/artlab/` URL
path. Serve the extracted files at that path with an HTTP server; it is not a
double-click offline application. GitHub also provides the tagged source archives.
