# Artlab v1.3.0

Artlab's examples now open as editable module compositions. Change an entry, a helper,
or a shared scene class, then run the complete JavaScript or TypeScript module graph
in the browser. Export preserves the source, dependencies, and example assets so the
composition can be reopened and edited again.

**Live app:** https://jordanhubbard.github.io/artlab/

## Editable source workspace

- Search **Environment source** to browse Artlab's implementation and open workspace
  copies of shared modules.
- Run relative imports, re-exports, circular imports, and literal dynamic imports.
- Use TypeScript entries and helpers; compilation reports syntax errors. Full
  TypeScript type checking is not part of Run.
- Preserve example source edits across reloads and export multi-file ZIP packages.
- Follow the Particle Storm tutorial from its composition into its effect and shared
  rendering classes.

## Reusable scene classes

Nine examples now share classes for scene composition, resource cleanup, instancing,
particle buffers, ordered trails, shader surfaces, microphone analysis, and gesture
buttons. Preview and standalone contexts use the same helper implementation.

Particle Storm uses one instanced mesh in place of 500 separate mesh objects. Trails
use fixed ring storage rather than shifting their history. These are structural
optimizations, not claims of a particular frame rate.

## Other changes since v1.2.0

- Higher-resolution solar-system textures.
- Restored project validation gates and more reliable Signal Salvage browser tests.
- Updated project narrative and documented scene architecture.
- Added **Long Winter**, an Amiga-inspired production design proposal. A tracker
  player and finished demo are future work and are not included in this release.

## Validation and distribution

The implementation passed lint, the production build, 526 unit tests, 54 gallery
browser checks, and 12 IDE/workspace integration tests. GitHub CI also passed for
the implementation commit. The release version bump was rebuilt successfully.

`artlab-v1.3.0-dist.zip` contains the production site built for the `/artlab/` URL
path. Serve the extracted files at that path with an HTTP server; it is not a
double-click offline application. GitHub also provides the tagged source archives.

Changes to imported scene modules take effect when Run rebuilds the composition.
Editing the running IDE host itself still requires rebuilding Artlab.
