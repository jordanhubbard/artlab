# Artlab v1.4.0

Artlab now includes **Long Winter**, a complete tracker-inspired audiovisual
performance. A tiny maintenance robot pulls a loose pixel from a frozen stage and
opens it into impossible architecture, a moving swarm, and an amber sun before the
show returns home.

**Live app:** https://jordanhubbard.github.io/artlab/#long-winter

## Long Winter

- One **Watch** gesture starts the 1:42 performance without requesting camera or
  microphone access.
- An original 112 BPM score supplies melody, chords, bass, and drums. Audible
  transport time is the visual master clock; a silent clock keeps the show available
  when browser audio cannot start.
- Six named passages transform one fixed 1,400-instance buffer from architecture into
  swarms and a sun, then return to Pip and the opening stage.
- Space pauses or resumes the transport, while the arrow keys seek by eight bars
  without accumulating frame-time drift.
- **Explore the score** shows live pattern, row, and voice activity. **Open this part**
  links the current passage to its editable source module.
- A rolling 20 ms p95 frame budget reduces instance density on slower devices without
  changing musical timing or composition.

## Composition and measurement

The score, transport, performer, world, transforming field, overlay, and entry scene
are separate modules. They reuse Artlab's `Scene`, `ResourceScope`, and `InstanceField`
ownership model and remain browsable and editable in the IDE.

End credits report live p50/p95 frame time, draw calls, active instances, resolution,
rendering path, browser, and platform. All geometry and sound are synthesized in the
browser; the production includes no external assets or third-party music licenses.

## Validation and distribution

The release passed lint, the production build, 533 unit tests, and the complete
browser gallery suite. The Watch, audio-start, score-seek, and transformation path was
also exercised directly in Chromium without console or preview errors.

`artlab-v1.4.0-dist.zip` contains the production site built for the `/artlab/` URL
path. Serve the extracted files at that path with an HTTP server; it is not a
double-click offline application. GitHub also provides the tagged source archives.
