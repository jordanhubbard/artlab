# Artlab v1.6.0 — Long Winter: Northern Light

Long Winter now pays tribute to the Amiga demoscene through detailed scenery,
reflective surfaces, and evolving mathematical sculptures. The earlier block robot,
flat scenery, and simple geometric props are replaced in the performance.

**Live demo:** https://jordanhubbard.github.io/artlab/#long-winter

If Artlab restores an older saved project, select **long-winter** in Examples again
(export any edits first), or open the link in a private window. The new start button
reads **WATCH NORTHERN LIGHT**. Use **FULLSCREEN** for the largest viewing area.

## Visuals

- Three sculpted mountain ranges, snow-covered instanced spruce forests, detailed
  timber cabin, patterned birch bark and branches, star field, and soft snowfall.
- Live planar reflections of the mountains, cabin, and aurora in a frozen fjord,
  with subtle distortion and frost veins.
- Five folded aurora curtains with animated vertical filaments and green-to-violet
  color gradients; a warm dawn closes the performance.
- Three full-resolution ray-marched acts: interwoven metallic knots, a reflective
  copper tunnel, and an unfolding twelve-petal iridescent sculpture.
- Computed normals, ambient occlusion, soft shadows, and a secondary reflection
  bounce give the sculptures lighting and depth. Rendering combines rasterized
  scenery with signed-distance sphere tracing, not progressive path tracing.
- Nine distinct songs remain synchronized to the performance clock, with act
  navigation, pause/resume, score inspection, and editable source links.

## Resolution and distribution

The ray marcher uses the drawing-buffer resolution without a low-resolution
upscaling pass. The host supports device pixel ratios up to 2; the lake's offscreen
reflection is 1024×1024. GPU cost increases with display resolution.

Validation passed lint, all 536 unit tests, the production build, the gallery smoke
test, and a browser regression that renders all nine acts and checks for shader
errors. Fullscreen output was also inspected at 1920×1080 and verified at
3840×2160. The release includes a 4K opening-scene capture.

`artlab-v1.6.0-dist.zip` contains the production site built for the `/artlab/` URL
path. Serve it from that path using an HTTP server. GitHub also supplies tagged
source archives.
