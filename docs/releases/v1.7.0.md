# Artlab v1.7.0 — Gallery Refresh and Strict TypeScript

Artlab refreshes its teaching gallery and completes the TypeScript migration
across the application, runtime, CLI, demos, tests, and build configuration.

**Live app:** https://jordanhubbard.github.io/artlab/

## New and refreshed lessons

- **Interference Atlas** explores complex-amplitude superposition, cancellation,
  and nodal curves with phase, wavelength, and source-separation controls.
- **Volume Observatory** integrates emission and absorption through a scalar
  field, with slice, density, and view controls.
- **Tidal Loom** rebuilds Wave Sculpture with 4,096 instanced fins, local wave
  slopes, height colors, and pointer-driven ripples.
- **Murmuration** rebuilds Flocking Boids with 900 birds, 1,800 instanced wings,
  spatial neighborhood queries, and fixed simulation timesteps.
- **Chronometer** combines the analog and kinetic clock lessons behind one style
  control. **Ember Engine** combines particle fountain and vortex behavior in one
  bounded simulation pool.

The gallery retains 55 active lessons. Old Clock Kinetic and Particle Storm links
resolve to their consolidated lessons, while the introductory cube and numbered
tutorials preserve their focused teaching role.

## Shared core and TypeScript

- All 234 repository TypeScript files receive strict semantic checking in one
  compiler project, including every demo and test. The temporary `noCheck` bypass
  and migration configurations are removed.
- Both browser hosts use the shared `SceneContext` and resource ownership model.
  Standalone execution cleans up successful, failed, and superseded runs.
- Shared sketch helpers cover staging, instancing, shader surfaces, controls,
  pointer input, seeded randomness, fixed timesteps, and spatial queries.
- The CLI scaffolds native `main.ts` lifecycle modules with the shared context
  and scoped input. Demo tests use a common typed context fixture.
- Development and the CLI require Node.js 22.18 or newer, with native TypeScript
  execution enabled by default.
- The gallery and browser smoke tests consume the same catalog. Editable helper
  modules survive running, exporting, reopening, and bookmarked-example reloads.

Strict repository checking does not add semantic diagnostics to the browser
editor. WebGL qualification does not establish WebGPU support or hardware frame
rates. See [the architecture and remaining boundaries](https://github.com/jordanhubbard/artlab/blob/v1.7.0/docs/demo-refresh.md).

## Validation and distribution

The implementation passed lint, strict TypeScript checking, 543 unit tests, the
production build, and all 78 Chromium browser tests. Release CI repeats these
checks on the versioned release commit before publication.

`artlab-v1.7.0-dist.zip` contains the production site built for the `/artlab/`
URL path. Extract it into a directory served at that path by an HTTP server.
It is not a double-click offline application. `SHA256SUMS` verifies the download;
GitHub also supplies tagged source archives.
